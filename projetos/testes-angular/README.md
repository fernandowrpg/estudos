# Projetos — Testes no Angular

Segue a trilha da Alura [Angular: cursos de testes automatizados para garantir a qualidade da sua aplicação](https://cursos.alura.com.br/app/learning-guide/alura/angular-testes-automatizados-garantir-qualidade-aplicacao).

| Pasta | Módulo | Parte da trilha | Cursos |
|---|---|---|---|
| `01-jest/` | 1 — Jest | Passo 01, curso 1 | Angular: implemente testes de unidade com Jest |
| `02-unidade-integracao/` | 2 — Unidade e integração | Passo 01, cursos 2 e 3 | Angular: expandindo funcionalidades com testes unitários e e2e · Angular: explorando testes de unidade e integração |
| `03-e2e-playwright/` | 3 — End-to-end com Playwright | Passo 02 | Angular: escreva testes end-to-end com Playwright · Angular: teste e otimize o fluxo de autenticação com Playwright |

Dentro de cada pasta, um subdiretório por projeto de curso (ex.: `01-jest/3618-organo-projeto-base/`).

O módulo 4 aplica o estudo numa biblioteca de componentes interna, que vive em outro
repositório. Aqui ficam só as anotações, em `notas/testes-angular/04-biblioteca-componentes.md`.
