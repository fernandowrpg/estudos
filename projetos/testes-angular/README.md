# Projetos — Testes no Angular

| Pasta | Módulo | O que é |
|---|---|---|
| `01-jasmine-karma/` | 1 — Jasmine e Karma | App pequeno para praticar specs, TestBed, spies e mocks |
| `02-jest/` | 2 — Jest | O mesmo app com Jest no lugar do Karma, mais serviços, HTTP e interceptors |
| `03-angular-moderno/` | 3 — Angular moderno | Signals, `httpResource`, rotas, component harnesses e cobertura |

O módulo 4 aplica o estudo numa biblioteca de componentes interna, que vive em outro
repositório. Aqui ficam só as anotações, em `notas/testes-angular/04-biblioteca-componentes.md`.
